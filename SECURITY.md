# Security Policy

This policy applies to every repository in the jobcelis-team organization: the Jobcelis platform and its official SDKs, CLI, GitHub Action and Terraform provider.

## Supported versions

Security fixes are released for the latest version of each package. Please upgrade to the latest release before reporting.

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue.

- **Preferred:** use **Report a vulnerability** in the repository's **Security** tab (GitHub private vulnerability reporting).
- **Email:** security@jobcelis.com

Include a description, steps to reproduce, the affected package and version, and the potential impact.

## What to expect

| Stage | Timeframe |
|-------|-----------|
| Acknowledgment | Within 24 hours |
| Initial assessment | Within 48 hours |
| Fix | Within 7 days for critical issues, 30 days otherwise |
| Public disclosure | After the fix is released |

We will keep you informed, credit you in the release notes unless you prefer otherwise, and will not take legal action against research done in good faith.

## Please do not

- Disclose the vulnerability publicly before it is fixed
- Access, modify or delete data that is not yours
- Run denial-of-service attacks or automated scanners against production
